# Роза ветров: сайт турагентства

## Описание

Многостраничный сайт турагентства «Роза ветров», которое продаёт туры в Мексику. На сайте можно подобрать тур по направлению, дате и бюджету, посмотреть фото и условия, оставить заявку на бронирование с дополнительными услугами, задать вопрос менеджеру и сохранить понравившиеся туры в избранное в личном кабинете.

## Используемый фреймворк

Bootstrap 5.3.3.

## Способ подключения

Bootstrap подключён через CDN (jsDelivr). Собственные стили лежат в `css/custom.css`.

## Структура проекта

- `index.html`: главная страница с подбором тура;
- `tours.html`: каталог туров с подбором и частыми вопросами;
- `tour.html`: страница выбранного тура
- `booking.html`: заявка на бронирование и сводка заказа;
- `account.html`: личный кабинет (избранное, заявки, профиль);
- `css/custom.css`: цвета проекта и дополнительные стили;
- `js/main.js`: подбор туров, избранное, формы, кнопка «Наверх»;
- `images/`: изображения проекта;
- `sitemap.xml`: карта сайта;
- `README.md`: описание проекта.
